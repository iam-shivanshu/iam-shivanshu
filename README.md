### Featured project

**[esp8266-dvr-motion-automation](https://github.com/iam-shivanshu/esp8266-dvr-motion-automation)** — turns an existing CCTV DVR's motion detection into automatic room control, with an ESP8266 per room and an optional Firebase web app for remote control from anywhere.
